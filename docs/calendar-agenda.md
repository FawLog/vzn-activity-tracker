# Agenda: upcoming events

Agenda defaults to the current UTC day and instant, with a 30-day window and forward/back paging (never before today). It separates ongoing events from today's and later starts, omits empty dates and elapsed events, and displays each occurrence once. Date-only schedules retain their actual date precision; the list does not invent a clock time or print Time not set. A timed event without an end is treated as a point, not assigned an assumed duration. Active multi-day events show their end, current day and reference stage where available. UTC end midnight retains the 24:00 convention for timed events. Agenda refreshes its current-time filter every 15 seconds and on focus/visibility change. Historical events remain accessible in Week and Month; past-date deep links open Week.

Agenda cards contain the event name, phase and useful timing, with confidence represented by the existing border and tooltip. Cancelled entries appear only when requested. Ownership, record state, internal grouping and linked metadata are not displayed in the Agenda list. Clicking an entry opens the existing event workspace. Week and Month grids and card layouts remain unchanged. No database/API/CI/deployment changes.
