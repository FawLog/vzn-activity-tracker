# Agenda: today and upcoming events

Agenda defaults to the current UTC day, with a 30-day window and forward/back paging (never before today). Today contains every event occupying the current UTC date, including completed timed events and multi-day events that started earlier. This keeps today's results and attendance entry accessible directly from Agenda. There is no separate Ongoing section. Date-only entries are first in each day, followed by timed entries in chronological order. Empty dates and events that ended before today are omitted; each occurrence is displayed once. Date-only schedules retain their actual date precision; the list does not invent a clock time or print Time not set. A timed event without an end is treated as a point, not assigned an assumed duration. Active multi-day events show their end, current day and reference stage where available. UTC end midnight retains the 24:00 convention for timed events. Agenda refreshes its UTC day every 15 seconds and on focus/visibility change; a completed event stays visible until the day changes. Historical events remain accessible in Week and Month; past-date deep links open Week.

Agenda cards contain the event name, phase and useful timing, with confidence represented by the existing border and tooltip. Cancelled entries appear only when requested. Ownership, record state, internal grouping and linked metadata are not displayed in the Agenda list. Clicking an entry opens the existing event workspace. Week and Month grids and card layouts remain unchanged. No database/API/CI/deployment changes.
