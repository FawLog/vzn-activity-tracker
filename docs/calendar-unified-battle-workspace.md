# One event card for all Foundry and Canyon phases
Every entry in a linked battle cycle opens the same event card, replacing the calendar grid while open. Registration and Battle results reuse the existing ManualEventEditor, with its legion tabs. Schedule settings are collapsed and optional. Loading a card is read-only; a missing legion needs its actual UTC start time, inline, once. Starting data entry confirms the relevant battle occurrence and links or creates the matching event/session in one transaction. A second legion not planned initially can be added to the current cycle without editing the recurrence. Existing results are reused and no attendance is fabricated. Unknown clock times are never invented. Standalone advanced schedules and non-battle event workflows retain their existing handling. No schema or CI/CD change.
## Other event types audited
Grouped Bear Trap entries share an event card across all traps and host alliances, including across UTC midnight. Mobilization and Championship have a single data-first card; the same multi-day occurrence opens the same record. Explicit "Confirm and open" combines schedule confirmation and lazy draft creation, with existing records reused and no automatic publication. Schedule-only events do not show unsupported linking controls; SvS uses the common cycle title and phase overview (no activity editor yet). Advanced ungrouped traps and standalone battle entries retain their explicit identity controls inside an advanced disclosure.
