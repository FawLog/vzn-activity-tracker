# Calendar v3.3 — create reviewed drafts

Explicitly create a draft and link in one SQLite transaction. Supported: Foundry, Canyon battle, Bear, Mobilization and Championship. Only confirmed alliance schedules. Battle sessions require a known UTC time and explicitly chosen identifier. Bear requires an explicit group cycle date (within seven days of the trap, a conservative review guard, not a game rule); search existing cycles before creation. Existing compatible drafts must be selected rather than duplicated. No automatic creation, publishing, roster or results. Non-battle main sections retain the existing date-anchor convention. Revision checks reject repeat submissions; a failed write rolls back all inserts. No schema or CI changes. Existing manual Events workflows remain available.
