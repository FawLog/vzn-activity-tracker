# Calendar v3.7 — lazy entry

Enter event data explicitly starts a transaction on a confirmed schedule; reads never create records. Single-section events reuse an exact unique owner/type/date record or create a draft. Foundry/Canyon reuse an exact unique host/time session or create a missing legion only when the phase explicitly identifies Legion 1/2. Existing links are retry-safe; ambiguous matches, duplicate links, missing time, estimated schedules and non-battle Canyon phases require review. Bear retains explicit group cycle and trap selection until v3.8. Existing manual linking is a fallback. No new OCR logic, participant writes, publication or analytics changes. No schema or CI changes. The first click prepares a draft even if the officer subsequently abandons entry; no drafts are created merely by opening a calendar entry.
