# Calendar v3.1 — explicit actual event links

Link existing alliance-owned Foundry, Canyon battle, Alliance Mobilization and Alliance Championship records by exact group, alliance, state, type and UTC start date. Multiple scheduled legion occurrences can point to one actual event; each occurrence has at most one actual event. No automatic creation, results, participation or analytics changes. Bear group cycles and host/session mapping require a separate increment. State events and catalog-only types are not supported. Links use explicit selection, revision checks, CSRF, audit, and cascade removal on actual event deletion. Linked schedules cannot be moved/cancelled or change identity until unlinked; event date changes also require unlinking. Reverse navigation opens calendar day and occurrence. No automatic matching, status promotion or result ingestion.
