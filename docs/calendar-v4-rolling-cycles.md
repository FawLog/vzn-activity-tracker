# Whole-cycle recurrence and reconciliation
New Foundry, Canyon and SvS schedules can maintain a 60-day rolling window from the chosen anchor using the existing hourly renewal. The selected initial cycle remains reviewed; forecasts are estimated with unknown local legion times. Renewal skips missed historical cycles, rejects conflicting phases atomically and stops on conflict. Finite repeating batches retain a series identity. Existing legacy cycles stay intact and are not silently enrolled.

Review cycle dates allows explicit confirmation of active/future cycle dates, one-cycle shift, shift of untouched future forecasts and renewal anchor, or stopping renewal without deleting existing entries. Shifts preserve confirmed, modified, cancelled, started and linked cycles; revision snapshots reject stale changes, overlapping proposals and existing results. Unknown local legion time remains unset after date confirmation. Source provenance stays manual/recurrence, with review audit entries; no external provider is connected. Changing repeat interval, importing external schedules and enrolling existing legacy cycles remain follow-ups.
