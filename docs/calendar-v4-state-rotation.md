# Calendar v4.5: state progression and rotation review
Open Calendar / More / State progression & forecast. The panel loads the group's active state opening profiles, 90 days of past calendar records, and 61 days of future calendar records. It uses the pinned Whiteout Survival Data 0.11.0 timeline for reference age, hero generations and upcoming milestone dates (heroes, pets, experts, events, fire crystal and other unlocks). These dates are estimates; state age does not establish a confirmed event occurrence.
Initial rotation coverage is Lucky Wheel, Hall of Heroes, Hero's Mission and the two SvS phases. Each requires a recent explicitly confirmed state-level anchor after reference unlock and a compatible fixed whole-day cadence; conflicting observed dates, known upcoming or cancelled occurrences suppress suggestions. No paid API or game scraping. Open a suggestion in the existing Add event editor, inspect and save a bounded estimated series. Renewal is opt-in. Time precision and recorded duration are retained; missing time or end remains unknown. No attendance or actual results are created. No database or CI changes.
This is intentionally conservative initial coverage, not an automatic universal rotation engine: Castle/SvS alternating weeks, King of Icefield calendar-month vs weekday, early Mobilization/Showdown rotation, multi-phase SvS construction and other events need explicit validated local rules. Existing future schedules are not reconciled or overwritten. State opening profiles come from free WhiteoutStats or a manual override.
