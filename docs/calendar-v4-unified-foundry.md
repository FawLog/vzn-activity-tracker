# Unified creation and Foundry cycles
One visible creation option per Bear, Foundry, Canyon and SvS. The single-trap and battle-only tools are internal advanced actions; legacy edits retain their original types. Foundry schedule supplement uses the official FAQ (checked 2026-11-28); weekdays remain estimated. Both battle legions are optional independent time slots in one linked event cycle, and future legion times are unknown. Each selected legion is assigned its shared battle date and identity; preparation phases cannot create results. Migration 0021 extends the cycle kind constraint without changing existing IDs. Finite cycle recurrence remains separate from indefinite renewal.
